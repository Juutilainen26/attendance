# 출석률 관리 (개인용)

특정 날짜부터 한 달 단위로 영업일을 세고, 결근·지각·조퇴를 체크할 때마다
100%에서 얼마나 떨어졌는지와 **80%를 지키면서 앞으로 더 쉴 수 있는 일수**를 보여주는 안드로이드 앱.

설치 방법은 **[설치안내.md](설치안내.md)** 를 보세요.

## 구조

```
www/                 앱 본체 (브라우저에서 index.html 열면 그대로 동작)
  index.html         화면 + 조작
  engine.js          계산 엔진 + 공휴일 데이터
  engine.test.js     단위 테스트 (node engine.test.js)
  manifest.json      PWA 설정
android/             WebView 껍데기 (www/ 를 그대로 assets 로 씀)
.github/workflows/   푸시하면 APK를 자동 빌드해 Releases에 올리는 설정
```

## 계산 규칙

| 항목 | 값 |
|---|---|
| 결근 (하루 통째) | 1.00 |
| 지각 | 0.33 |
| 조퇴 | 0.33 |
| 지각 + 조퇴 (같은 날) | 0.66 |

- 영업일 = 월~금 중 법정공휴일·대체공휴일·개인 지정 휴무일 제외
- 출석률 = (영업일 − 사용량) ÷ 영업일 × 100
- 여유 한도 = 영업일 × (100% − 기준 출석률)
- 기간 = 시작일 ~ 다음 달 시작일 전날, 매달 자동 반복

## 테스트

```bash
cd www && node engine.test.js
```
